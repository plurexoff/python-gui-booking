# Приложение для бронирования столика

Простое GUI приложение на Python с использованием библиотеки Tkinter.
Выполнено в рамках задания №4 "Графический интерфейс пользователя (GUI)".

## Функционал
- Форма ввода данных (Имя, Дата, Количество гостей)
- Валидация полей
- Обработка нажатия кнопки
- Вывод подтверждения брони

## Запуск
Для запуска приложения убедитесь, что у вас установлен Python.

```bash
python booking.py
```
