# Приложение для бронирования столика

Простое GUI приложение на Python с использованием библиотеки Tkinter.
Выполнено в рамках заданий №4 (GUI) и №5 (Тестирование).

## Структура проекта
- `booking.py` - Графический интерфейс (Assignment #4)
- `booking_logic.py` - Основная логика приложения (выделена для тестирования)
- `test_booking.py` - Юнит-тесты на базе pytest (Assignment #5)

## Запуск приложения
Для запуска GUI:
```bash
python booking.py
```

## Тестирование
Для выполнения задания №5 используется библиотека **pytest**.

### 1. Установка зависимостей
```bash
pip install pytest pytest-cov
```

### 2. Запуск тестов
Простой запуск всех тестов:
```bash
pytest
```

### 3. Проверка покрытия кода (Code Coverage)
Запуск тестов с отчетом о покрытии:
```bash
pytest --cov=booking_logic
```
Ожидаемый результат: 100% покрытие бизнес-логики.
